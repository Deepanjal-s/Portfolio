Suggested fixes, largest first

  1. 81% of misses are ranked too low: the evidence was found but didn't fit. Add a cross-encoder re-ranker over the top 50-100 candidates (in memory-recall-bench's own LongMemEval run it lifted all-evidence recall at 4k from 63% to 71%). Prefer this over a bigger budget: more context can lower answer accuracy.
  2. 61% of misses are incomplete (some needed sessions in, others out). Typical of questions that combine facts across conversations; a re-ranker helps most here, query expansion a little.
  3. 12% of misses are never retrieved: the first stage never finds the evidence. Add the missing signal: BM25 if you only use embeddings, embeddings if you only use keywords (fused with RRF), and check chunk size against your embedding model's limit.
  4. 13 misses have mixed causes (one session never found, another ranked too low).
